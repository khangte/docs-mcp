검색이 두 갈래인 이유

사람이 문서에 적힌 것과 똑같은 단어로 묻는 경우는 드물다. 그래서 한 가지 방법만으로는 놓친다.

이 설계에서 중요한 것 세 가지

01

서버는 답을 쓰지 않는다

문장을 만드는 일은 AI 쪽에 맡기고, 서버는 근거가 될 문서를 고르는 일만 한다. 역할이 갈려 있어 답이 이상할 때 문서를 잘못 찾은 것인지, 읽고 잘못 쓴 것인지를 구분할 수 있다.

02

흩어진 문서를 한 창구로

Google Drive, Notion, API 명세는 서로 다른 곳에 있고 검색 방식도 제각각이다. 이 서버를 거치면 어디에 있든 같은 방식으로 한 번에 찾는다.

03

사람이 챙기지 않아도 최신

문서가 바뀌면 정해진 주기에 서버가 알아서 다시 읽어 온다. 여러 갱신 작업이 동시에 돌아도 서로 부딪히지 않도록 순번을 지키게 해 두었다.

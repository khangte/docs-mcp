# ADR-0001: 저장형 검색 구조 채택

- 상태: accepted
- 일시: 2026-04-29
- 관련: ARCHITECTURE.md §1, plan.md §15-3

## 컨텍스트
OpenAPI 문서를 Claude와 같은 LLM이 활용할 때, 실시간으로 대용량의 Swagger JSON을 읽는 것은 컨텍스트 윈도우 낭비와 응답 속도 저하를 초래한다. 또한, 문서가 복잡할수록 필요한 엔드포인트를 찾는 데 어려움이 있다.

## 결정
OpenAPI 문서를 실시간 프록시하지 않고, 사전에 수집·정규화하여 로컬 데이터베이스(PostgreSQL)에 저장하고 색인하는 **저장형 검색 구조**를 채택한다.

## 결과
- 장점: 검색 속도 향상, 키워드/벡터 하이브리드 검색 가능, LLM에게 필요한 정보만 선별하여 제공 가능.
- 단점: 문서 최신성 유지를 위한 별도의 동기화(Sync) 로직이 필요함.
- 후속 영향: `ingestor`, `parser`, `indexer` 서비스 구현 필요.

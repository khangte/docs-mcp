# ADR-0003: MCP 도구의 읽기 전용 경계 유지

- 상태: accepted
- 일시: 2026-04-29
- 관련: ARCHITECTURE.md §5, plan.md §7-2

## 컨텍스트
MCP 서버가 실제 운영 API를 호출하거나 리소스를 변경하는 기능을 가질 경우 보안 및 안정성 리스크가 발생할 수 있다.

## 결정
본 프로젝트의 MCP 도구는 오직 OpenAPI 문서의 **검색 및 상세 정보 조회** 기능만 제공하며, 실제 API 호출(Execute) 기능은 범위에서 제외한다.

## 결과
- 장점: 보안 사고 예방, 검색 품질에만 집중 가능.
- 단점: LLM이 API를 직접 테스트해볼 수는 없음.
- 후속 영향: `mcp_server.py`에는 조회용 도구(search, get_details 등)만 등록.
